# macOS KakaoTalk Ad Remover

카카오톡 메인·잠금 화면의 광고 영역과 빈 공간을 숨기는 **비공식 실험용 로컬 패처**입니다.
카카오톡 원본 앱이나 리소스를 배포하지 않습니다.

> **계정 이용 제한 가능성**
>
> 이 도구는 Kakao Corp.의 승인·지원·보증을 받지 않았습니다.
> 사용자의 카카오톡 실행 파일을 수정하고 **로컬로 재서명**합니다.
> 카카오의 약관·운영정책에 따른 계정/서비스 이용 제한, 실행·로그인·업데이트 오류가
> 발생할 수 있습니다. 무제재, 계정 안전성 또는 정상 동작을 보장하지 않습니다.
> 위험 고지가 법적 책임을 일괄 면제한다는 뜻은 아닙니다.
> 원본 복구 기능으로 서버 측 이용 제한을 해제할 수는 없습니다.
>
> [카카오 약관](https://www.kakao.com/policy/kakaoTerms) ·
> [카카오톡 운영정책](https://talksafety.kakao.com/policy/stability/abnormalusage)

## 지원 범위

- macOS 12 이상, Python 3.9 이상.
- 현재는 **카카오톡 26.9.0 (2006)의 확인된 Universal 실행 파일과 화면 리소스만** 지원합니다.
  버전 번호가 같더라도 해시가 다르면 적용하지 않습니다.
- 페이로드는 arm64/x86_64로 빌드합니다. 이 프로젝트에서 수행한 런타임 검증은 Apple Silicon 기준입니다.
- 원본 화면 리소스를 이용한 격리된 레이아웃 실험과 자체 AppKit 테스트를 수행했습니다.
  **로그인한 실제 계정의 장기 사용·송수신·계정 안전성은 검증한 것이 아닙니다.**
- 광고 영역의 표시를 제어하는 도구입니다. 광고 서버 통신 전체를 차단하는 도구가 아닙니다.

자세한 검증 범위는 [검증 기록](docs/verification.md)을 참고하세요.

## 명령 한 번으로 설치

프로젝트 또는 배포 ZIP을 푼 폴더에서 실행합니다.

```sh
./install.sh
```

위험 고지에 동의하면 **필요한 빌드 → 카카오톡 정상 종료 → 백업 → 패치·서명 검증 → 재실행**을
이어 진행합니다. 빌드된 배포 파일이 있으면 다시 컴파일하지 않습니다.
작업 전에 실행 중이던 카카오톡만 다시 엽니다. 종료가 거부되거나 끝나지 않으면 강제 종료하지 않고 중단합니다.
이미 패치된 앱은 변경하거나 종료하지 않습니다.

확인 질문 없이 위험 동의를 옵션으로 명시하려면 다음 명령 하나를 사용합니다.

```sh
./install.sh --accept-risk
```

원본 복구도 한 번에 실행합니다.

```sh
./install.sh --restore
```

다른 설치 경로는 `--app '/경로/KakaoTalk.app'`, 자동 재실행을 원치 않으면 `--no-relaunch`를 추가합니다.
처음부터 `sudo`로 실행하지 마세요. 쓰기 권한이 필요할 때 파일 작업에 한해서 관리자 암호를 요청합니다.
macOS의 권한·보안 확인을 자동 승인하지 않습니다.

Python 3.9 이상이 필요합니다. 소스에서 처음 빌드하거나 소스가 바뀌었다면 Apple Command Line Tools도
필요합니다. 필수 도구가 없으면 설치 방법을 안내하고 중단합니다.

고급 사용자는 기존의 `python3 patcher.py status`, `apply --accept-risk`, `restore` 명령도
사용할 수 있습니다. 이 하위 명령들은 앱을 자동 종료·재실행하지 않습니다.

원본은 앱 옆의 숨김 폴더 `.KakaoTalk.app.kakao-ad-remover/original.app`에 보관됩니다.
패치 사용 중 이 폴더를 삭제하지 마세요. 중간에 중단됐다면 `status`를 확인하고 `restore`로 복구합니다.
설치본이 패치 이후 다른 버전으로 바뀌면 자동 복구로 덮어쓰지 않고 백업을 보존합니다.
**App Store 업데이트 전에는 먼저 복구하세요.** 새 버전은 지원 목록에 추가되기 전까지 적용할 수 없습니다.

## 동작

반복 감시나 100ms 타이머를 사용하지 않습니다. 앱이 광고 뷰·높이 제약을 연결하거나
변경할 때만 네이티브 훅이 개입합니다. 광고 높이와 구분선을 0으로 유지하고 광고 뷰를 숨깁니다.
인증·로그인 초기화 메서드는 교체하지 않습니다.

패처는 복사본을 준비하고, 우리 라이브러리의 로드 명령을 추가하고, 서명을 검증한 뒤
설치본과 교체합니다. 원본 entitlements를 유지하면서 로컬 라이브러리를 로드할 수 있도록
앱에 `disable-library-validation` 예외를 추가합니다. 공식 서명 신원은 유지되지 않으므로
macOS의 새 권한 확인이나 키체인/앱 기능 문제가 발생할 수 있습니다.
채팅 데이터·계정 정보를 읽거나 수정하지 않으며, 로그를 외부로 전송하지 않습니다.

## 개발 및 패키징

```sh
bash scripts/test.sh
bash scripts/package.sh
```

배포 ZIP에는 자체 작성한 패처 코드와 빌드한 페이로드만 들어갑니다.
`analysis/`, `probe/`, 앱 복사본, 카카오 실행 파일, `.nib`, `Assets.car`는 Git과 배포물에 포함하지 않습니다.

카카오톡 및 관련 상표·프로그램·리소스의 권리는 각 권리자에게 있습니다.
