# Local KakaoTalk Patcher Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for inline execution.

**Goal:** Ship a local, reversible, event-driven patcher with clear risk disclosure.

**Architecture:** A pure Mach-O editor adds our payload to a prepared app copy.
An installer verifies and atomically activates it while retaining a restore copy.
The Objective-C payload intercepts ad view/constraint changes without polling.

**Tech Stack:** Python 3 standard library, Objective-C/AppKit, Apple command-line tools.

**Spec:** `docs/design.md`

## Global Constraints

- No 100 ms polling or any periodic timer.
- No Kakao executable, resource, private data or analysis artifacts in Git/releases.
- Warn about account restrictions, signing changes and lack of account-safety guarantees.
- Apply only after `--accept-risk`; never automatically launch the modified app.
- Preserve a verified original for restore; refuse unsupported versions and active apps.

## Review Focus

- Malformed or insufficient Mach-O header space must not overwrite program bytes.
- Failed staging/signing must leave the original app available.
- Symlinked paths must not direct writes outside the selected bundle/state directory.
- App Store replacement must not be overwritten with an older restore copy.
- Hooks must not affect unrelated views/constraints or authenticated lifecycle methods.

### Task 1: Mach-O patching

**Files:** `kakao_patch/macho.py`, `tests/test_macho.py`
**Interface:** `inject_dylib(data: bytes, name: str) -> bytes`; `entitlements(data) -> dict`.

- [x] Write and run failing tests for thin/fat injection, idempotence, malformed tables,
  insufficient padding, byte preservation, and entitlement extraction.
- [x] Implement pure parsing/editing and make the full Python suite pass.

### Task 2: Native hooks

**Files:** `src/AdBlock.m`, `tests/hooks.m`, `scripts/build.sh`, `scripts/test.sh`.
**Interface:** A universal `build/KakaoAdBlock.dylib`, loaded by a Mach-O load command.

- [x] Write an actual AppKit harness: inherited setters, zero-height collapse,
  attempted restoration, replacement outlets, resizing, and unrelated view isolation.
- [x] Observe failure without hooks; implement targeted event hooks and rerun.

### Task 3: Installer and distribution

**Files:** `kakao_patch/app.py`, `kakao_patch/cli.py`, `patcher.py`, `tests/test_app.py`,
`README.md`, `scripts/package.sh`, `.github/workflows/test.yml`.
**Interface:** `status`, `apply --accept-risk`, `restore`; no automatic activation on launch.

- [x] Test risk acceptance, support checks, stopped-app check, apply/restore,
  failed signing, symlinks, interrupted swap and updated-app refusal using real files.
- [x] Implement transactions and CLI; run tests and test against an isolated app copy.
- [x] Package only authored code and payload; verify archive contents and Git ignores.
- [x] Fresh review, fix material findings, run final suite and create the initial implementation commit.
